
# Literature Review References

## AI-Powered Remote Patient Monitoring – Predictive Healthcare Analytics Platform

This document contains the primary research papers reviewed during the
literature study for the AI-Powered Remote Patient Monitoring project.

The selected literature covers:

- Remote Patient Monitoring (RPM)
- Internet of Things (IoT) in healthcare
- Machine Learning for physiological data analysis
- Predictive healthcare analytics
- Clinical deterioration and early-warning systems
- IoT/IoMT security and privacy
- Multi-parameter vital-sign monitoring

---

## 1. Personalized Blood Pressure Control by Machine Learning for Remote Patient Monitoring

**Citation:**

Mai, V. T., Alattas, K. A., Bouteraa, Y., Ghaderpour, E., & Mohammadzadeh, A.
(2024). Personalized blood pressure control by machine learning for remote
patient monitoring. *IEEE Access, 12*, 83994–84004.

**DOI:**  
https://doi.org/10.1109/ACCESS.2024.3413572

**Relevance:**

Demonstrates the application of machine learning and deep reinforcement
learning to personalized physiological monitoring and blood-pressure control.
The study provides motivation for incorporating intelligent analysis into
Remote Patient Monitoring systems.

https://doi.org/10.3390/healthcare11162240

**Full Text:**  
https://pmc.ncbi.nlm.nih.gov/articles/PMC10454027/

## 3. Remote Vital Sign Monitoring in Admission Avoidance Hospital at Home: A Systematic Review

**Citation:**

Patel, R., Thornton-Swan, T. D., Armitage, L. C., Vollam, S., Tarassenko, L.,
Lasserson, D. S., & Farmer, A. J. (2024). Remote vital sign monitoring in
admission avoidance hospital at home: A systematic review.
*Journal of the American Medical Directors Association, 25*(8), 105080.

**DOI:**  
https://doi.org/10.1016/j.jamda.2024.105080

**PubMed:**  
https://pubmed.ncbi.nlm.nih.gov/38908399/

**Relevance:**

Examines remote vital-sign monitoring across 21 randomized controlled trials
involving 3,459 participants. The study supports the use of continuous and
automated physiological monitoring outside conventional hospital
environments.

# Identified Research Direction

The reviewed literature demonstrates that IoT-based physiological monitoring
and machine-learning-based health analysis are active areas of research.

However, existing approaches frequently concentrate on individual diseases,
specific physiological parameters, isolated prediction tasks, or individual
components of a Remote Patient Monitoring system.

The proposed project aims to investigate an integrated approach combining:

- Multi-parameter physiological monitoring
- Heart Rate, SpO2, Blood Pressure and Body Temperature
- IoT-based real-time data acquisition
- Historical physiological trend analysis
- Data preprocessing and feature engineering
- Machine-learning-based anomaly detection
- Predictive risk assessment
- Normal / Warning / High Risk classification
- Real-time alerts
- Patient and healthcare-professional dashboards
- Secure API communication
- Authentication and Role-Based Access Control (RBAC)

The system is intended as a remote monitoring and decision-support prototype
and not as an automated medical diagnostic system.

# Planned Machine Learning Evaluation

Candidate machine-learning algorithms will be experimentally evaluated during
the implementation phase.

Potential models include:

- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest
- XGBoost

The models are planned to be compared using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

Experimental results will be added after dataset selection, preprocessing,
model training and evaluation.
